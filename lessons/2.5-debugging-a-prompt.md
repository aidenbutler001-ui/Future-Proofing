## Read
When a prompt fails, don't rewrite it. Debug it:
1. **Find a failing input** and keep it.
2. **Read the bad output** and say what's wrong in a sentence.
3. **Form a guess** about which part of the prompt caused it.
4. **Change one thing**, run all your inputs again, and compare.
5. **Keep a log**: what changed, what improved, what got worse.

Fixing one case can break another. That's why you rerun every input each time.

## Puzzle: Fix the prompt that fails on edge cases
You get a working-ish prompt for summarizing meeting notes and 6 test notes. It fails on three: empty notes, notes in two languages, and notes with no decisions. You have 5 edits.

- Goal: all 6 pass without making a passing one fail.
- Hidden tests: 2 extra notes beyond the visible 6.
- Grader: rules per note. A note that passed before and fails now is flagged as a regression.

## Hints
1. Reproduce before you edit.
2. A rule for the empty case may change how every case ends.

## Reflect
What would you have missed if you had only checked the three failing notes?
