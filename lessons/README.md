The on-ramp (S.1 to S.3) comes first: a quick real win, then Module 0 (data safety). Module 0 and its rules come back as an "Opsec check" in most later lessons. The material on agents running on a computer that holds confidential files waits until the agent section (lesson 4.0). Module 1 covers the landscape, the basic mechanism and the capabilities, focused on LLMs. Image, video and audio models are planned as later add-on components.

The course builds toward Module 6, where learners design, build and defend a real automation. Module 7 (judgement and safety) closes the core track; safety also appears earlier, inside Modules 3 to 6. Module 8 is the living "Frontier" module: shorter briefs that get a quarterly review and swap in new topics.

Module 3 covers working with documents and retrieval. Tools are taught in Module 4 (as agents are introduced) and Module 5 (as part of the harness).

Each file has the same parts: Read, Example, an Opsec check where data or access is involved, Puzzle (goal, hidden tests, grader), Hints, Reflect, and a "Right now" box for anything tied to current tools. Frontmatter holds a review date so stale lessons can be flagged.
