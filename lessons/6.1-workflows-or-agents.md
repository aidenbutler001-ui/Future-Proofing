## Read
Both a workflow and an agent use models and tools. The difference is who decides the steps.

- **Workflow (pipeline):** *you* decide the steps in advance, and the model does the work inside each one. "Extract the fields, then check them, then file the record."
- **Agent:** *the model* decides the steps as it goes (lesson 4.3).

| | Workflow | Agent |
|---|---|---|
| Predictable | High | Lower |
| Cost and speed | Lower, steady | Higher, varies |
| Handles surprises | Poorly | Better |
| Easier to test | Yes | Harder |
| Best for | Repeated tasks with known steps | Open-ended tasks with unknown steps |

**Start with the simplest thing that works.** A single prompt, then a short workflow, then an agent, only when each earlier option falls short. Many successful automations are plain workflows with a model in two or three steps.

Real systems mix both: a workflow with an agent inside one step, or an agent that can start a workflow as a tool.

## Puzzle: Choose the shape
You get 8 jobs (invoice intake, research a competitor, answer a customer chat, weekly report, debug a failing build...). For each, choose single prompt, workflow or agent, and name the first step you'd build.
- Goal: 7 of 8 match the key's accepted answers.
- Hidden tests: the 8 jobs; two have more than one defensible answer (justify), one is overbuilt if you pick an agent.
- Grader: answer key with accepted ranges; feedback compares your choice's cost and risk to the simpler option.

## Hints
1. Could you write the steps on paper today?
2. What happens when step 3 returns something unexpected?
