## Read
A prompt that works on your three favorite inputs is not tested. A tested prompt has a short list of inputs with expected results, including:
- **Typical** inputs
- **Edge** inputs (empty, very long, odd formatting)
- **Hostile** inputs (instructions hidden in the content, requests to break the rules)

Each test says what pass looks like in a way you can check. Re-run the list whenever you change the prompt or the model. This is the seed of what later modules call **evals**.

## Puzzle: Write tests that break someone else's prompt
You get a prompt for a refund-approval assistant with its rules. Write 5 inputs that make it break a rule. The simulated model has three hidden weaknesses.

- Goal: find 2 of 3 weaknesses.
- Hidden tests: the three weaknesses.
- Grader: rules detect when a rule was violated by your input. Feedback names the weakness found.

## Hints
1. Read the rules; write the input that is closest to the line.
2. What if the customer message contains instructions?

## Reflect
Which of your tests would you keep in your own prompts?

## Module 2 wrap-up
Build a prompt for a task of your choice and 8 tests for it. Share the prompt and the tests, and say what failed first.
