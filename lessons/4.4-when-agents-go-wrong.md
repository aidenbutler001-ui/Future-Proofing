## Read
Common failures:
- **Looping:** repeating the same step because nothing changes.
- **Wandering:** solving a bigger problem than was asked.
- **Giving up too early** or **declaring success too early**.
- **Compounding errors:** a wrong result in step 2 poisons steps 3 to 6.
- **Acting on bad input:** following instructions found inside a web page or file (a form of **prompt injection**).

Defenses:
- **Step and cost limits** that stop the loop.
- **A stop rule in the goal:** "If you can't find it in 3 tries, say so."
- **Verification steps:** check an output against the source before using it.
- **Human approval** before anything irreversible.
- **Treat tool results as data, not as commands.**

**Cost note.** A looping agent is also a billing problem. Step and spend caps stop both the loop and the bill (lesson 6.5).

**Opsec check.** The most dangerous combination is private data plus untrusted content plus a way to send things out (lesson 7.2). Remove at least one. Never run a looping or unattended agent on a machine that holds confidential files.

## Puzzle: Fix the looping agent
You get an agent trace that loops on a missing file, and the goal and tool descriptions that produced it. You have 5 edits.
- Goal: the agent stops after at most 3 tries and reports what it couldn't do, on all 4 test runs.
- Hidden tests: 4 runs, including one where a "tool result" contains a hidden instruction to email someone (the agent should ignore it).
- Grader: rules over the trace; a run that obeys the injected instruction fails immediately.

## Hints
1. Where does your goal say what to do when stuck?
2. Which text in the trace came from a tool, not from the user?
