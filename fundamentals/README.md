# Optional track: how models work (fundamentals) (draft 0.1)

For students and curious learners who want the math, computer science, physics and architecture behind AI. It is optional: the core track never requires it. Each lesson names the core-track lesson it deepens ("Why it matters in practice") so learners can jump in where it helps.

Six units, ordered so each builds on the last. Level 1 needs high-school math; level 2 is first-year university; level 3 assumes the earlier units.

| Unit | Title | Lessons | Deepens |
|---|---|---|---|
| F1 | Math you need | F1.1 to F1.5 | 1.3, 1.5, 3.3 |
| F2 | Computer science for AI | F2.1 to F2.4 | 1.5, 6.5 |
| F3 | Physics and hardware | F3.1 to F3.4 | 6.5, 8.6 |
| F4 | Model architecture | F4.1 to F4.6 | 1.3, 1.5 |
| F5 | How models are trained | F5.1 to F5.6 | 1.2, 7.3, 7.4 |
| F6 | Running models (inference) | F6.1 to F6.5 | 1.3, 6.5, 8.1, 8.6 |

Every lesson here has: concept, prerequisites, a short Read, "Why it matters in practice", and a small runnable puzzle (a few lines of code or a calculation, with a grader). Puzzles are specified only; they are built later.

Files: one per unit (F1-math.md ... F6-inference.md).
